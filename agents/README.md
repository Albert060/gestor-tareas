# Agentes Locales del Proyecto

Este directorio contiene los agentes locales para el flujo de trabajo de desarrollo perfeccionista del proyecto.

## Estructura de Agentes

### 1. [architect.md](./architect.md) - Arquitecto Software PERFECCIONISTA
- **Rol**: Análisis detallado de requerimientos y diseño de arquitectura
- **Enfoque**: Meticuloso, ordenado, perfeccionista
- **Salida**: Especificaciones completas y diagramas de arquitectura

### 2. [developer.md](./developer.md) - Desarrollador Software PERFECCIONISTA
- **Rol**: Implementación de código limpio y eficiente
- **Enfoque**: Sin duplicados, legible, mantenible
- **Salida**: Código implementado con estándares de calidad

### 3. [auditor.md](./auditor.md) - Auditor de Calidad PERFECCIONISTA
- **Rol**: Revisión y mejora de implementaciones
- **Enfoque**: Análisis exhaustivo, corrección de errores
- **Salida**: Código auditado y mejorado

### 4. [tester.md](./tester.md) - Tester de Calidad PERFECCIONISTA
- **Rol**: Creación de suites de testing exhaustivas
- **Enfoque**: Cobertura total, identificación de bugs
- **Salida**: Tests completos con 100% de cobertura

### 5. [documenter.md](./documenter.md) - Documentador Técnico PERFECCIONISTA
- **Rol**: Documentación técnica actualizada
- **Enfoque**: Precisión absoluta, versionado semántico
- **Salida**: Documentación completa y actualizada

## Flujo de Trabajo

```bash
# 1. Comenzar con el Arquitecto
/architect "Implementar [feature] con requerimientos: [detalles]"

# 2. Continuar con el Desarrollador
/developer "Implementar basado en especificaciones del arquitecto"

# 3. Luego el Auditor
/auditor "Auditar implementación del desarrollador"

# 4. Seguido por el Tester
/tester "Crear suite de testing para la feature auditada"

# 5. Finalmente el Documentador
/documenter "Documentar feature completada"
```

## Características Comunes

Todos los agentes comparten estos principios perfeccionistas:

- **Atención al detalle**: Nada se deja al azar
- **Calidad absoluta**: Estándares mínimos de excelencia
- **Documentación completa**: Todo está registrado
- **Testing exhaustivo**: 100% de cobertura
- **Versionado preciso**: Semver estricto

## Cómo Usar

1. Cada agente está diseñado para trabajar en secuencia
2. Ningún agente pasa al siguiente hasta cumplir con sus estándares
3. La salida de un agente es la entrada del siguiente
4. Todos los agentes son locales y específicos del proyecto

## Nota Importante

Este sistema de agentes sigue la filosofía de que la perfección no es opcional, es el estándar mínimo. Cada agente asegura que su trabajo esté impecable antes de pasar al siguiente.
